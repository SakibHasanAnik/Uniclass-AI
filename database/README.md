# Database

**Owner:** Sakib Hasan Anik (Team Leader)

PostgreSQL database. Tables are created from the Django models in `backend/*/models.py` using migrations.

| File / Folder | Contents |
|---|---|
| `er_diagram.png` | Entity-relationship diagram |
| `schema_notes.md` | Every table and column explained |
| `sample_queries.sql` | SQL used in the report (averages, attendance %, risk counts) |
| `backups/` | Database backup of the demo data |

**Main tables:** User, StudentProfile, Course, ClassSchedule, Enrollment, Material, Assignment, Submission, Assessment, Mark, Attendance, AdvisorStudent, RiskScore, Intervention
